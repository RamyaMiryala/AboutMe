# Ramya Miryala - Personal Portfolio

Built on the **Spectral (HTML5 UP)** template design, preserving all original content, links, press archives (2012–2026), profiles, and social connections.

## Publish on GitHub Pages
1. Extract all files from this ZIP archive.
2. Open your repository `ramyamiryalaofficial.github.io` on GitHub (`github.com/ramyamiryalaofficial`).
3. Upload all extracted files (`index.html`, `README.md`, `LICENSE.txt`, `assets/`, and `images/`) directly to the root of the repository (`index.html` must be in the root folder).
4. Go to **Settings > Pages > Source**, select **Deploy from a branch**, choose `main` and `/ (root)`, then click **Save**.
5. Your site will be live at `https://ramyamiryalaofficial.github.io` within 1–2 minutes.

## Customizing
- **Profile Photo:** Add your high-resolution photo as `images/ramya.jpg` (until added, it automatically falls back to your official portrait URL).
- **Telugu Intro:** In `index.html`, replace the placeholder line (`ఇక్కడ మీ గురించి తెలుగులో ఒక చిన్న పరిచయం రాయండి.`) inside the `#about` section with your Telugu bio.
